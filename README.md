# Telegram-бот расписания мероприятий VK Education

Go-бот хранит события на любой срок вперёд. Управление выполняется в личной переписке с ботом, а уведомления отправляются во все подключённые владельцем группы и каналы. Для рубежного контроля сообщение отправляется за 1 день, для предзащиты и защиты проекта — за 2 дня. Окно отправки — с 10:00 включительно до 22:00 исключительно по часовому поясу `Europe/Moscow`.

## Запуск

1. Создайте бота через `@BotFather` и получите токен.
2. Создайте конфигурацию:

   ```sh
   cp .env.example .env
   ```

3. Запишите токен и надёжный пароль в `.env`.
4. Запустите одним из способов:

   ```sh
   set -a
   source .env
   set +a
   go run ./cmd/schedulebot
   ```

   или через Docker:

   ```sh
   docker compose up -d --build
   ```

При локальном запуске данные сохраняются в `./data/events.json`; Docker Compose использует постоянный том `schedule-data`.

## Первый вход

Откройте личный чат с ботом и отправьте:

```text
/login ПАРОЛЬ_ИЗ_BOT_PASSWORD
```

Первый пользователь, который введёт правильный пароль, становится единственным владельцем. Привязка сохраняется в `./data/auth.json`. Сообщение с паролем бот автоматически удаляет. После пяти неверных попыток вход блокируется на 15 минут.

После входа добавьте бота в нужные группы со своего Telegram-аккаунта. Бот автоматически запомнит каждую группу и пришлёт подтверждение вам в личку. Все команды продолжайте отправлять только в личной переписке: команды в группах игнорируются, и туда приходят только уведомления. Каждое событие рассылается во все подключённые группы и каналы.

## Команды

```text
/add checkpoint ГГГГ-ММ-ДД ЧЧ:ММ НОМЕР_РК ССЫЛКА_НА_ВЕДОМОСТЬ
/add predefense ГГГГ-ММ-ДД ЧЧ:ММ
/add defense ГГГГ-ММ-ДД ЧЧ:ММ
/test ШАБЛОН ...
/clear
/leave
/leaveall
/list
/delete ID
/chatid
/resetowner ПАРОЛЬ
/help
```

Чтобы немедленно отправить заполненный шаблон в подключённую группу без сохранения события, замените `/add` на `/test`. Команда `/clear` удаляет из группы тестовые сообщения, отправленные после последнего запуска бота.

Команда `/leave` заставляет бота покинуть только подключённую группу или канал. `/leaveall` покидает все известные ему группы и каналы и очищает привязку доставки.

Команда `/resetowner ПАРОЛЬ` доступна только текущему владельцу. Она удаляет сообщение с паролем и сбрасывает Telegram user ID, сохраняя группы и расписание. После неё новый владелец выполняет `/login ПАРОЛЬ`.

Доступные шаблоны: `checkpoint`, `predefense`, `defense`.

Примеры:

```text
/add checkpoint 2027-04-20 18:00 РК1 https://example.com/sheet
/add predefense 2027-05-15 12:30
/add defense 2027-06-01 09:00
```

Тексты сообщений собраны в каталоге `templates/`: `checkpoint.txt`, `predefense.txt` и `defense.txt`. Бот подставляет в них дату, время, день недели, номер РК и ссылку на ведомость. После редактирования шаблонов перезапустите бота.

## Постоянный запуск на Linux

Готовый systemd-unit находится в `deploy/schedulebot.service`. Он запускает бота отдельным непривилегированным пользователем, предоставляет запись только в `/var/lib/schedulebot` и автоматически перезапускает процесс после сбоя или перезагрузки сервера. Бот использует только исходящие HTTPS-соединения и не требует открытия портов или изменения firewall.

Планировщик проверяет события сразу после запуска, а затем в начале каждого часа. Если бот был выключен в момент отправки, он отправит просроченное напоминание после запуска, пока событие ещё не началось. После успешной отправки событие помечается, поэтому повторное уведомление не уйдёт.

Если расчётное время напоминания раньше 10:00, оно переносится на 10:00 того же дня. Время 22:00 или позже переносится на 10:00 следующего дня. Просроченные уведомления также ожидают ближайшего разрешённого окна и никогда не отправляются ночью.
