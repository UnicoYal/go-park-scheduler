# Telegram-бот для уведомления о расписании

Требования: 
- Возможность создавать расписание на 6+ месяцев вперед
- За день до события отправлять сообщение в телеграмм чат
- Заранее подготовленные шаблоны для сообщений(Рубежный контроль, предзащита проекта, защита проекта)
- Язык программирования — Go

Реализация и инструкция по запуску находятся в [README.md](README.md).
